Vocabulary Voice Coach

A simple working prototype of a voice agent that helps people learn vocabulary: the coach speaks each word, you repeat it aloud, and a quiz checks the meaning. No sign-up, nothing stored.

How it works

  1. Speak - the coach reads each word, its meaning and an example aloud using the browser's speech synthesis.
  2. Repeat - you say the word back, and the browser's speech recognition checks whether it heard the right word. Tapping works too.
  3. Quiz - you say or tap the word that matches a meaning, and the coach keeps score across the deck.

Honest limits

This is a front-end prototype. It uses the Web Speech API with rule-based lesson logic. It is not connected to a large language model, so it cannot hold a free-form conversation yet. Voice input needs a browser with speech recognition (Safari on iPhone, Chrome or Edge on Android or a computer; Brave does not include it) and a tap on the microphone button to allow mic access. Every step also works with taps. When voice input is active, speech is processed by the browser's speech recognition service (for example Apple's in Safari or Google's in Chrome), which may send that audio to the provider. This page itself records, stores and sends nothing.
